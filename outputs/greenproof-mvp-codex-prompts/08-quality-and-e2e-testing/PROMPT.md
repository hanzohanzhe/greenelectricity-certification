# Codex任务：08 数据质量、安全边界与端到端测试

请对模块02—07进行系统性验证，修复发现的问题，并建立可持续运行的自动化测试。

## 目标

验证从公开数据下载、标准化、场景构建、多租户分配、前端展示到哈希证明的整条链路，而不是只测试单个函数。

## Golden Dataset

建立一个小型可提交Git的Golden Dataset，至少包含：

- 48个半小时区间；
- 一个共享光伏；
- 两个租户；
- 白天过剩上网；
- 早晚电网购入；
- 至少一个1Wh舍入边界；
- 一个缺失区间的无效版本；
- 一个被篡改1Wh的版本。

人工或独立脚本计算预期结果，并固定：

- 区间分配；
- 日汇总；
- 场景哈希；
- Merkle根；
- 一条Merkle路径。

## 数据管道测试

覆盖：

- 下载缓存命中和失效；
- 外部API超时、限流和字段变化；
- CSV列缺失；
- Parquet损坏；
- 源文件哈希不匹配；
- UTC/BST切换；
- 46、48、50个半小时Settlement Period；
- 负值、重复、回零、异常零值；
- 小数到整数Wh的余量处理；
- 实测和模型标签不混淆。

外部网络测试与普通CI测试分离；CI默认使用fixture。

## 引擎属性测试

对大量随机输入验证：

```text
sum(tenantAllocation) == onsiteMatched
onsiteMatched + export == generation
sum(tenantGridImport) == gridImport
tenantAllocation <= tenantDemand
all values >= 0
```

## 前端E2E

用Playwright覆盖：

1. 加载默认场景；
2. 切换场景；
3. 移动时间滑块；
4. 选择Tenant A/B；
5. 切换分配规则；
6. 检查页面数值与场景预期一致；
7. 打开Evidence；
8. 生成证明；
9. 验证证明；
10. 加载损坏场景并显示错误。

测试桌面和移动宽度，并做基本无障碍检查。

## 安全与隐私边界

确认：

- 页面和日志不显示未经授权的精确建筑身份；
- 不把原始住址写进URL；
- 不在代码中硬编码API密钥；
- 不把原始大数据提交Git；
- 哈希承诺不被描述为匿名化；
- 演示证明显著标为非正式；
- 不出现“100%纯绿”“已减排多少”等无法支持的绝对声明。

## 复现测试

在干净环境执行：

1. 安装依赖；
2. 使用fixture构建场景；
3. 运行匹配引擎；
4. 构建前端；
5. 生成和验证证明。

文档化一条从零开始的命令路径。

## 验收标准

- 所有CI测试通过。
- Golden Dataset结果固定且有解释。
- 修改任一输入1Wh会使证明验证失败。
- 无网络环境仍可运行完整演示。
- 数据来源和标签在UI、manifest和引擎结果中一致。
- 没有高严重性依赖漏洞；无法修复的需记录。

## 完成后

更新本模块 `LOG.md`，记录测试矩阵、覆盖结果、发现并修复的缺陷、未解决风险和最终复现命令。
