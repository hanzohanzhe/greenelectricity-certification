# 05 开发日志：多租户匹配与分配引擎

- 状态：完成
- 算法版本：greenproof-matching/1.0.0

## 实现

实现 `pro_rata_demand_v1`、`priority_v1`、`contract_share_v1`。所有运算
使用整数 Wh；比例分配采用确定性最大余数法，同余时按租户稳定顺序。
固定份额先受各租户负荷上限约束，再按份额对剩余可用量进行重分配。

## 测试

固定 48 区间 Golden Dataset、500 组随机输入 × 三规则、零发电/负荷、
1 Wh 舍入、超额份额、时间错位和大数均验证。所有区间严格满足生成、
现场消纳、上网、购电和租户分配守恒。

## 边界

质量标记存在时结果为 `provisional`；缺失、重复、重叠或不同粒度在
进入引擎前拒绝。
