# Three-minute pilot demonstration

1. **0:00–0:30 — Establish the boundary.** This is one shared 60 kWp modelled
   rooftop serving two anonymous real-demand building shapes. Point out the
   public-data disclaimer.
2. **0:30–1:10 — Move through the day.** In Site Twin, drag from night to noon.
   Show grid import before sunrise, simultaneous rooftop allocation, then any
   midday export.
3. **1:10–1:40 — Explain the rule.** Switch from pro-rata to Tenant A priority
   and 60/40 contract. The physical totals stay fixed; only tenant attribution
   changes.
4. **1:40–2:10 — Reconcile the period.** Open Period Summary. Compare total
   generation, onsite use, export and each tenant's same-interval local share.
5. **2:10–2:45 — Inspect evidence.** Open source details, provenance and
   limitations. Generate the demo proof and show the manifest and Merkle root.
   Simulate a 1 Wh change to show verification failure.
6. **2:45–3:00 — Ask for the pilot.** Explain that the next phase replaces three
   series—PV, Tenant A and Tenant B—without changing the engine or UI.

End by repeating: not a formal certificate, not an emissions claim, not
blockchain-anchored.
